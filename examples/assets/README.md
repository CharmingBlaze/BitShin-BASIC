# Example assets

Original checker textures and a short coin beep made for BitShin BASIC. CC0 — not from any commercial game. Regenerated with `go run tools/gen_platform64_assets.go`.

| File | Role |
| --- | --- |
| `grass.png` | 32×32 green checker for the ground |
| `heightmap.png` | Written by `examples/heightmap.bb` (`SaveHeightmap`) |
| `stone.png` | 32×32 tan checker for platforms |
| `coin.png` | 32×32 gold disc |
| `coin.wav` | ~125 ms 988 Hz beep |
| `midtown_walk.geojson` | Short WGS84 walk + point for `examples/geo.bb` |
| `terrain/*.png` | CC0 splat maps (`go run tools/gen_terrain_assets.go`) — not Nintendo, not Terrain-OpenGL photos |
